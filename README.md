# ⚔️ RPG Flutter

Projeto desenvolvido para a disciplina de Programação Mobile, um jogo de RPG por turnos feito em Flutter.

## O que é

Um app mobile onde você cria heróis, escolhe raça e arquétipo, e os manda batalhar na arena. O sistema de combate é por turnos com dados, habilidades especiais e log de batalha em tempo real.

## Funcionalidades

- Criar heróis com nome, raça e arquétipo
- Cada combinação gera uma imagem diferente do personagem
- Batalha por turnos com barras de vida animadas
- Habilidades especiais reais — Guerreiro bloqueia ataques, Mago causa dano dobrado, Arqueiro sempre ataca primeiro
- Histórico de batalhas com horário e vencedor
- Deletar personagens deslizando o card

## Como rodar
```bash
git clone https://github.com/EduLovatelW/rpg_app_flutter.git
cd rpg_app_flutter
flutter pub get
flutter run -d chrome
```
